CORE Warden — Privacy Policy

Last updated: [fecha]

CORE Warden is a Discord bot developed in Python that supports community operations, tournament management, application review, and automation of administrative tasks. This Privacy Policy explains what data we collect, how we use it, and how users can control it.

1. Data We Collect

  • Discord user IDs, guild (server) IDs, channel IDs, and message IDs.
  • Tournament applications (guild name, leader, member count, average level, rewards plan).
  • Tournament data (brackets, matches, results, winners).
  • Application review data (status: PENDING, APPROVED, REJECTED).
  • Audit logs of administrative actions.

We do NOT store message content. Messages are processed in real time only to execute prefix commands (e.g., !guildapply, !tournament_start).

2. How We Use Data

  • Managing tournaments and brackets.
  • Reviewing guild applications.
  • Assigning or removing roles based on application status.
  • Generating match reports and tournament status.
  • Maintaining audit logs for security.

3. Data Storage

Data is stored in a local SQLite database on the bot's host server. It is not shared with third parties, not sold, and not used for advertising.

4. Message Content

CORE Warden does not store message content off-platform. Message content is only read in real time to process commands. It is not logged, persisted, or used to train machine learning or AI models.

5. Opt-Out and Data Deletion

Users can opt out by not using the bot's commands. Users can request deletion of their data by contacting us at [tu-email]. We will process deletion requests within a reasonable timeframe.

6. Future Features

CORE Warden is being designed to include, in future versions:

  • AI-assisted chat moderation and quick responses.
  • A punishments system storing evidence, reason, duration, and moderator.
  • A ticket system with role-based escalation.
  • A staff activity tracker (online time).

When these features are implemented, this Privacy Policy will be updated, and users will be given opt-out options where applicable. Message content will not be used to train AI models.

7. Security

Access to stored data is restricted to the CORE Warden team. We use access controls to protect data against unauthorized access.

8. Changes to This Policy

We may update this Privacy Policy. Continued use of CORE Warden after changes constitutes acceptance.

For questions or data deletion requests, contact: [tu-email]
