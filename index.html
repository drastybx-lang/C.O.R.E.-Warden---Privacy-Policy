Privacy Policy

CORE Warden

Community Operations & Response Engine — a Discord bot built for tournaments, applications, moderation, and community automation.

📅 Last updated: 12-09-2026 🛡️ Data Protection
01

Data We Collect

CORE Warden stores only the minimum data required to operate its features:

  • Discord user IDs, guild (server) IDs, channel IDs, and message IDs.
  • Tournament applications — guild name, leader, member count, average level, rewards plan.
  • Tournament data — brackets, matches, results, and winners.
  • Application review data — status: PENDING, APPROVED, REJECTED.
  • Audit logs of administrative actions.
We do NOT store message content. Messages are processed in real time only to execute prefix commands such as !guildapply or !tournament_start.
02

How We Use Data

All collected data is used exclusively to provide CORE Warden's core features:

  • Managing tournaments and generating brackets.
  • Reviewing guild applications and updating their status.
  • Assigning or removing roles based on application results.
  • Generating match reports and tournament status.
  • Maintaining audit logs for security and transparency.
03

Data Storage

Data is stored in a local SQLite database hosted on the bot's own server. It is not shared with third parties, not sold, and not used for advertising. Access is restricted to the CORE Warden team and protected with access controls.

04

Message Content

CORE Warden does not store message content off-platform. Message content is read in real time solely to process prefix commands. It is not logged, not persisted, and never used to train machine learning or AI models.

05

07

Security

Access to stored data is strictly limited to the CORE Warden team. We apply access controls and best practices to protect all data against unauthorized access, alteration, or disclosure.
